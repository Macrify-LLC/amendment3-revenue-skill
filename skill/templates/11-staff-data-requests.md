# Data requests to staff

When the plan needs a number that isn't published, don't guess it and don't stop. Add a request here, addressed to the department that has it, in plain words, saying why it's needed and what format helps. Give the user the list to send.

**To:** [Department]  **From:** [User]  **Re:** Information for the Amendment 3 revenue analysis  **Needed by:** [date, worked back from the calendar]

| # | What we need | Why we need it | Format that helps | Department |
|---|---|---|---|---|
| | Fire/rescue incidents for the last [3-5] years, by property type (residential, commercial, industrial, institutional, vacant) and by call type (fire, medical, other) | To divide fire costs fairly by property type, and to separate ambulance/medical costs, which can't be charged as an assessment | Spreadsheet from the dispatch/records system (NFIRS/CAD) with property use code, call type, date | Fire Rescue |
| | How the fire department's costs split between fire service and medical/ambulance service | Medical costs must be left out of a fire assessment | Cost allocation workpapers or unit-hour data | Fire Rescue / Budget |
| | Current fees and what share of each program's cost they cover | To see which programs could recover more from fees | Fee schedule and program cost reports | Each department / Budget |
| | Program list with cost, staffing, and funding sources | For the program-by-program review | Program budget or prioritization scoring | Budget |
| | Impervious area by parcel and the current ERU definition | To size a stormwater charge | GIS layer or rate study | Public Works / Engineering |
| | Units served and contract rates for solid waste | To size a solid waste charge | Billing extract | Solid Waste / Utilities |
| | Parcels the government owns or leases, and exempt parcels | To decide which parcels are charged or bought down | List with parcel IDs | Real Estate / Property Appraiser |
| | Building square footage by parcel (better than the state roll's "effective area") | Rates by building size | Property appraiser building extract | Property Appraiser |
| | Interlocal agreements for fire, EMS, library, and any shared service | To see how county-administered revenue is shared | The agreements and recent amendments | City/County Attorney |
| | Whether the property appraiser and tax collector will agree to the March 1 deadline | Decides whether a new assessment can be on the next tax bill | Letter or email | Manager / Attorney |
